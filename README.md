# AuthCore

**A Complete, Reusable & Production-Ready Authentication Framework for Node.js**

## Overview

Tired of writing the authentication module from scratch for every new project? 

**AuthCore** is a powerful, modular, and highly configurable authentication solution built for Node.js developers. It provides everything you need from user registration to advanced security features, so you can focus on building your product instead of reinventing auth every time.

Whether you need JWT + Refresh Tokens, sessions, Role-Based Access Control (RBAC), or multi-database support, AuthCore has you covered with clean architecture and best security practices.

## Features

- **Multiple Authentication Strategies**  
  Support for JWT (stateless), Session-based, and hybrid authentication

- **Role-Based Access Control (RBAC)**  
  Flexible role and permission management with middleware support

- **Secure Token Management**  
  JWT Access + Refresh Tokens with proper rotation and revocation

- **Email & OTP Verification**  
  Built-in email verification, password reset, and OTP/HOTP support

- **Advanced Security**  
  Rate limiting, brute-force protection, input validation, and secure password handling

- **Multi-Database Support**  
  Works seamlessly with PostgreSQL, MySQL, and MongoDB using Prisma ORM or Drizzle ORM

- **Clean Architecture**  
  Well-organized with DTOs, Zod schemas, Repositories, Services, Controllers, Middleware, and Routes

- **Highly Configurable**  
  Enable/disable features based on your project needs

- **Docker Support**  
  Ready for containerized environments

## Tech Stack

- **Runtime**: Node.js + Express
- **Language**: TypeScript
- **Validation**: Zod
- **ORMs**: Prisma ORM & Drizzle ORM
- **Databases**: PostgreSQL, MySQL, MongoDB
- **Caching & Sessions**: Redis
